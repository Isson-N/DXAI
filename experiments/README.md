# experiments — протокол валидации (план v2, раздел 2)

Файлы создаются `tools/make_folds.py` из `data/index/images.csv` и **не меняются** после начала экспериментов.

| Файл | Что |
|---|---|
| `folds.csv` | исследование → внешний фолд (0–4). `StratifiedGroupKFold` по исследованиям; страта — самое редкое нарушение изображения; сид выбран только по равномерности распределения положительных редких целей (не по моделям). Внутренние фолды = остальные внешние |
| `label_policy.csv` | расхождения «Итог» ↔ критерии (№6, 11, 35): цель «есть нарушение» = OR критериев по указанию организатора, масок нет |
| `feasibility.csv` | число положительных/отрицательных изображений и исследований по каждой цели во внешних тестовых фолдах и во внутренних обучающих частях |

Итог проверки (17.09.2026, сид 1): во всех 20 внутренних обучающих частях (5 внешних × 4 внутренних фолда) есть
оба класса каждой из 7 целей; минимум положительных изображений во внутренней обучающей части: укладка поясницы 3,
область интереса бедра 3, ось 5, предметы 9;
во внешних тестовых фолдах положительных исследований: укладка поясницы 1–2, ось 2, область интереса бедра 1–2,
предметы 3–4, укладка бедра 4–5, «есть нарушение» поясница 6–7, бедро 5–6 (после перехода на OR критериев 17.09).
