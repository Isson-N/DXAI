# Слепой повторный пересмотр метки «ось»

Инструмент: `tools/axis_review.py` (написан astra 20.09.2026, проверен дымовым прогоном).
Схема сохранения `dxa-axis-review/1`.

## Зачем

Метка «ось позвоночника отклонена» не согласуется ни с одним из проверенных признаков:
десять гипотез отвергнуты (`experiments/axis_label_audit_2026-09-20.md`). Осталось
измерить воспроизводимость самой разметки и — главное — **узнать, что человек вообще
видит на этих снимках**. Список причин, который заполняется после каждого вердикта, и
есть ответ на вопрос, который не смогли дать отвергнутые гипотезы.

**Чего этот пересмотр не доказывает** (поправка astra): κ и потолок F1 — разные
показатели, и низкое κ не «объясняет» F1 = 0,48. В отчёте оба числа идут рядом,
без причинной связки: «воспроизводимость метки ограничена: κ = X, положительное
согласие = Y» и отдельно наблюдаемый потолок.

## Процедура (её надо соблюсти, иначе результат ничего не значит)

1. **Не смотреть перед пересмотром** ни исходные метки, ни ошибки модели, ни углы.
   Инструмент их не показывает, но память о них смещает решения так же.
2. Если пересматривает тот же человек, что размечал, — выдержать интервал
   (это измерит внутриэкспертную согласованность). Второй человек измерит
   межэкспертную, это ценнее, но не всегда доступно.
3. Один заход — один сеанс, одинаковое отображение снимков (не менять яркость экрана
   и масштаб окна между сеансами).
4. Исходный `data/index/images.csv` зафиксировать: если метки в нём изменятся,
   отчёт сравнит пересмотр уже не с тем, с чем надо.

## Запуск

```bash
cd ~/projects/dxa-quality-ai
.venv/bin/python tools/axis_review.py \
    --reviewer isson --part 1 --clean-pixels-confirmed      # часть 1
.venv/bin/python tools/axis_review.py \
    --reviewer den   --part 2 --clean-pixels-confirmed      # часть 2
```

Работа делится по исследованиям, **25 снимков достаются обоим** — по ним считается
межэкспертное согласие, которое ценнее внутриэкспертного (его меряют скрытые повторы).
Без `--part` размечается вся выборка. Порт по умолчанию 8768 — 8765 занят старым
разметчиком позвоночника.

Флаг `--clean-pixels-confirmed` — подтверждение, что на снимках нет надписей,
вшитых в пиксели: метаданные инструмент не рисует, но выжженный в изображении
текст скрыть не может.

Адрес обычный: `http://127.0.0.1:8768/`, работать в одной вкладке. Порядок снимков
перемешан с фиксированным seed, исходная метка не показывается ни до ответа, ни после.

Ответы: `1` — отклонена, `2` — норма, `0` — не могу решить; затем уверенность
и причины (список раскрывается **после** вердикта — чтобы сам список не подсказывал
критерий). Возврат назад разрешён, изменение ответа отмечается флагом `revised`.

Если сервер упал — останется `*.json.lock`; удалить вручную, убедившись, что
прежний процесс завершён.

## Отчёт

```bash
.venv/bin/python tools/axis_review.py --report 'data/annotations/axis_review_*.json'
```

Печатает: таблицу «исходная метка × новый вердикт», Cohen's κ с бутстрэп-ДИ,
простое и **положительное** согласие (важнее κ при распространённости 10 %),
точный тест Макнемара на систематический сдвиг, список расхождений в TSV и
распределение причин отдельно для совпадений, расхождений и неопределённых ответов.
«Не могу решить» в κ не входит, но его доля печатается — это тоже мера
неоднозначности метки.

Если файлов два и больше (два раунда или два человека) — считаются попарные κ.

## Что делать с результатом

- **Причины у расхождений** — главное. Если у спорных положительных всплывёт
  «поворот таза» или «непараллелен краю кадра», это подскажет признак, которого
  мы не проверяли (проверенные и отвергнутые — в `experiments/axis_label_audit_2026-09-20.md`).
- κ и положительное согласие идут в раздел ограничений отчёта.
- Метку из основной macro-F1 **не исключаем** (решение по astra): вариант без «оси»
  приводится только как анализ чувствительности.
