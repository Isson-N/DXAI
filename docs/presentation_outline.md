# Защита, 5 минут: план выступления

Черновик, числа обновляются по мере готовности. Правило: ни одной цифры без того, как она получена.

## 1. Задача одним слайдом (30 с)

Оценить качество укладки при DXA-денситометрии: 5 нарушений из закрытых списков, две области
(поясничный отдел, проксимальный отдел бедра). Данные: 252 уникальных изображения, размечено 249,
редкие классы — от 6 до 36 положительных на нарушение.

## 2. Что мы поняли про данные (60 с)

- **Дубли:** 127 групп, пиксели совпадают байт в байт — считаем по уникальным изображениям, иначе
  метрика завышается.
- **Размер пикселя:** заявлено 1,05 × 0,6 мм, фактически в выгрузке 0,600 × 0,606 (подтверждено
  `ExposedArea`, пропорциями тел позвонков и измеренным шагом центров 31 мм).
- **Ловушка:** область (поясница/бедро) угадывается по размеру кадра с F1 = 1,00 — это свойство
  выгрузки, а не снимка, поэтому в сервисе область определяет модель по содержимому.
- **Противоречия разметки** (№6, №11, №35) разобраны и зафиксированы политикой
  (`experiments/label_policy.csv`), метки не «подгонялись».

## 3. Протокол оценки (45 с)

5 внешних фолдов по исследованиям, внутренний цикл для порогов и гиперпараметров, 95% ДИ —
кластерный бутстрэп по исследованиям. Сравнение моделей — только парным бутстрэпом: при 6–36
положительных точечные F1 неразличимы. Ограничение честно названо: группировать по пациенту
нечем, все идентификаторы в выгрузке обезличены.

## 4. Главный результат: измерять, а не угадывать (90 с)

| метка | CNN (сквозная классификация) | геометрия по предсказанным точкам |
|---|---|---|
| укладка поясницы | F1 0,46 | **F1 0,909** (TP 5, FP 0, FN 1) |
| ось позвоночника | AUC 0,57 | **AUC 0,881** |

Модель ключевых точек (soft-argmax, U-Net на resnet18) находит центры тел Th12–L5 и вершины
гребней с медианной ошибкой 3–5 мм; угол оси — с ошибкой 0,65° при пороге ТЗ 5°. Для сравнения,
повторная ручная разметка одним человеком: 2,78 мм и 0,34°.

Ручная разметка (99 снимков, ~70 минут) использовалась как **oracle** — потолок качества, —
а не как вход модели: на инференсе её нет.

## 5. Честная граница метода (45 с)

Метка «не выровнена ось» **не является функцией угла оси**: у 5 из 10 положительных угол 2,4–4,5°,
у отрицательных доходит до 6,4°, и кривизна их не разделяет. Поэтому F1 по этой метке упирается
в 0,48 при любом пороге — и максимум достигается ровно на 5° из ТЗ. Мы это показываем, а не прячем:
измерение верное, определение метки требует уточнения у эксперта.

## 6. Сервис (45 с)

CLI + API пакетной обработки, Docker без доступа в сеть, фиксированные версии и сиды, кеш прогноза
по хешу пикселей, отчёт из 9 колонок по ТЗ. Отдельно обрабатываются битые DICOM (строка `Failure`)
и файлы без изображения.

## 7. Что дальше (15 с)

Разметка ориентиров бедра (малый вертел, шейка) — там у нас пока только CNN; уточнение определения
метки «ось» у эксперта; доменная предтренировка на открытых DXA поясницы.
