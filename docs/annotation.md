# Разметка поясниц (этап 2 плана v2)

Программа: `tools/spine_annotator.py` — веб-страница в браузере, без установки дополнительных пакетов
(нужны pydicom, numpy, Pillow). Данные не покидают машину: сервер слушает только `127.0.0.1`.
Правила разметки — вкладка **«Инструкция»** внутри программы.

99 снимков поясницы делятся на две части: **часть 1 — 56 снимков, часть 2 — 53**, из них **10 общих** —
их размечают оба (так считаем согласие разметчиков). Разбиение детерминированное, одинаковое у всех.

## Запуск

Нужны данные организатора (`data/train/`) и индекс `data/index/images.csv`:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements-analysis.txt -e ".[dev]"
.venv/bin/python tools/build_index.py          # один раз: создаёт data/index/images.csv
.venv/bin/python tools/spine_annotator.py --index data/index/images.csv --root . --annotator <имя латиницей> --part <1|2>
```

Открыть **http://127.0.0.1:8765** в браузере.
Если программа запущена на удалённом сервере через VS Code Remote-SSH — VS Code обычно сам предлагает открыть
проброшенный порт; иначе вкладка **Ports → Forward a Port → 8765**. Без VS Code: `ssh -L 8765:127.0.0.1:8765 <сервер>`.

- Разметка сохраняется после каждого действия в `data/annotations/spine_points_<имя>.json`; можно закрыть и продолжить.
- Кто размечает какую часть: **Isson-N — часть 1, коллаборатор — часть 2**.
- Файл результата **не коммитить** (он производный от данных организатора, папка в `.gitignore`) — передать лично.

## Как размечать (кратко)

| Клавиша / действие | Что делает |
|---|---|
| клик по снимку | ставит текущую точку (подсказка сверху справа) |
| **N** | точки нет: вне кадра / не видно |
| **U** | не определить (наложение, неясно) |
| **1 / 2 / 3** | гребень: в кадре / частично / вне кадра |
| **Y / H / C** | Th12: видно ≥ половины / < половины / не определить |
| **Z** | отменить последнее действие |
| **Enter** или **→** | следующий снимок (только если текущий завершён); **←** — назад |
| колесо мыши, правая кнопка / пробел | масштаб, перемещение; «Вписать» — весь снимок |

Порядок на снимке: Th12↑, Th12↓, L1↑ … L5↓ (середины верхней и нижней замыкательных пластинок тела),
затем гребень слева и справа на экране, затем флаг Th12. Сомневаетесь — **U** и комментарий.

Рекомендуемый порядок работы: 10–15 снимков → свериться друг с другом и с инструкцией → остальные.
Время на снимке считается автоматически (`seconds_spent`).

## После разметки

```bash
.venv/bin/python tools/merge_spine_points.py data/annotations/spine_points_<имя1>.json data/annotations/spine_points_<имя2>.json \
    --out data/annotations/spine_points_merged.json
```
Печатает согласие на общих снимках: среднее расстояние между точками (мм), разницу угла оси, совпадение состояний
гребней и флага Th12.
