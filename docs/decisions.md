# Журнал развилок: что выбрано, что осталось в запасе

Каждая строка — точка, где было несколько разумных путей. Записано: варианты, выбранный путь,
причина и **чем переключить обратно**. Нужен, чтобы через неделю не гадать «почему так» и чтобы
альтернативу можно было проверить за один запуск, а не переписывать код.

Обозначения: ✅ — идём этим путём, ◻ — в запасе, ✖ — отвергнуто с причиной.

## 1. Порог решения (метрика организатора — F1)

| | Вариант | Статус | Чем включить |
|---|---|---|---|
| а | Максимум F1 на внутренних OOF | ✅ сейчас | по умолчанию |
| б | Центр широкой почти оптимальной области F1 | ◻ проверить рядом с (а) | `--threshold-tolerance 0.02` |
| в | Ограничение снизу на специфичность | ◻ запас | `--min-specificity 0.9` |
| г | Порог по усреднённой по фолдам кривой | ✖ | при 6–36 положительных фолд даёт 1–7 событий, шум больше выигрыша |

**Почему так.** Организатор считает F1 и точность по пяти нарушениям, поэтому оптимизируем F1.
Вариант (в) даёт мало ложных срабатываний и был бы правильным в клинике, но по F1 проигрывает:
на синтетической проверке при `min-specificity 0.9` F1 падал с 0,54 до 0,40. astra против (в)
как основного пути; держим как запасной, если организатор объявит, что точность важнее.
Вариант (б) — компромисс: та же цель, но порог устойчивее к одному-двум наблюдениям.

**Как вернуться:** оба флага уже есть в `training/train_baselines.py`, переобучение ~15 мин на V100.

## 3. Каналы входа

| | Вариант | Статус | Чем включить |
|---|---|---|---|
| а | Серый, повторённый 3 раза (статистики ImageNet) | ✅ для B1 (замороженный энкодер) | `--channels gray` |
| б | Снимок + лапласиан + маска валидной области | ✅ для B2 (дообучение) | `--channels physical` (по умолчанию) |

Маска нужна, чтобы сеть отличала настоящий край кадра от нулевого паддинга: «обрезанное поле
сканирования» — это метка про края. Для замороженного энкодера физические каналы не годятся:
он обучен на статистиках ImageNet.

## 5. Ось позвоночника

| | Вариант | Статус |
|---|---|---|
| а | Сквозная классификация CNN | ✖ AUC 0,57, ДИ накрывает 0,5 |
| б | Правило «угол > 5°» по ручным точкам | ✖ как решающее: F1 0,48 (TP 5, FP 6, FN 5) |
| в | Модель ключевых точек → геометрические признаки → логрег | ✅ этап 4 |
| г | Предобучение детектора точек на AASCE/VertebraeKeypoints50 | ◻ запас, если своих 99 снимков не хватит |

Причина отказа от (б): при сколиозе центры ложатся на дугу, МНК даёт ложный наклон;
на снимках с малой кривизной AUC хорды 0,888, на всех — 0,79.

## 5А. Представление ключевых точек

| | Вариант | Статус | Числа |
|---|---|---|---|
| а | Тепловые карты + MSE по гауссиану (первая версия) | ✖ не обучилось | ошибка точек 83–142 мм при ширине снимка 180 мм, угол мимо на 24–30°, карты размытые (средний максимум 0,34–0,58) |
| б | Soft-argmax (пространственный softmax → координаты) + L1 + KL к целевому пятну + голова присутствия | ✅ | на 15 эпохах одного фолда: точки 6–12 мм, угол 0,66–0,79° |
| в | Прямая регрессия координат из global-pool | ◻ контрольный baseline (совет astra) | — |
| г | Предобучение на AASCE → донастройка на DXA | ◻ проверять отдельной абляцией | — |

Причина провала (а): 39 «горячих» пикселей на 36 864 — при 60 обучающих снимках выгоднее
предсказать пустой фон, чем найти пик. Одного штрафа за разброс мало: центр может быть верным
при размазанном распределении, поэтому добавлен KL к целевому гауссиану (σ = 5 px входа).
Скорость обучения энкодера снижена до 1e-4 против 3e-4 у декодера и голов.

### Как пользоваться журналом

Новая развилка — новый раздел, сразу с вариантами и способом переключения. Когда запасной
вариант проверен, статус меняется на ✅/✖ и рядом ставится число, по которому решили.

**Где живёт альтернатива.**

- Если она включается флагом и код не меняется (пороги, разрешение, каналы) — ветка не нужна:
  в журнале записывается точная команда, результат кладётся в свою папку
  `experiments/results/<вариант>/`, числа попадают в `experiments/runs.md`.
- Если для неё нужен другой код (отдельные модели по областям, другая архитектура) — ветка
  `alt/<имя>` от текущего `main`, и ссылка на неё в этой таблице. В `main` такие ветки
  вливаются, только если вариант победил по внешнему CV.
- Отвергнутый вариант не удаляется из журнала: строка остаётся с ✖ и причиной.
