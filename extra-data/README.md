**Как использовать E1.** Жёлтые линии разметки позвонков можно выделить по цвету → получаем бесплатные
ориентиры L1–L4 (границы позвонков, контуры тел) на настоящих DXA того же производителя. Это готовая
обучающая выборка для модели позвонков, без ручной разметки. Перед обучением линии вырезать
(inpainting), иначе модель будет искать жёлтые линии. Th12 и гребней подвздошных костей в кадре нет.

## Как это использовать

- **Синтез нарушений из КТ (C1, затем C2/C3)** — главный кандидат.
  Инструменты: DiffDRR (PyTorch, `pip install diffdrr`) или DeepDRR. Схема:
  1. КТ → параллельная AP-проекция (DXA — это не перспективный рентген, а сканирующий пучок)
     → пиксель 0,6 мм, 8 бит, контраст «кость на тёмном фоне», маскирование фона как в данных организатора;
  2. маски TotalSegmentator/CTSpinoPelvic1K дают позвонки, гребни подвздошных костей, бёдра;
  3. **метки бесплатно:** поворачиваем объём в корональной плоскости → «Не выравнена ось позвоночника»
     с известным углом; сдвигаем окно кадра → «Некорректная укладка» (Th12 или гребни вне кадра);
     поворачиваем бедро вокруг оси → «Некорректная укладка» бедра (ротация, размер малого вертела);
     сужаем поле вокруг бедра → «Некорректная область интереса»;
  4. доменный разрыв DRR ↔ настоящая DXA закрывать аугментациями и дообучением на данных организатора;
     проверять только на данных организатора.
- **Предобучение точек позвонков (B1, B2, B4)** — если классической геометрии не хватит.
  AP-рентгенограммы поясницы ближе всего к DXA поясницы по анатомии, но контраст другой.
- **Посторонние предметы (D1)** — предобучение детектора посторонних объектов на рентгене грудной клетки;
  верхний край поясничного DXA-кадра захватывает ту же зону, где у нас чаще всего косточки бюстгальтера.
  Какие именно предметы размечены в object-CXR, проверить после скачивания.
- **Эндопротезы и переломы (B7, D2)** — примеры для устойчивости: организатор не разметил бёдра с эндопротезами,
  сервис не должен на них падать.
- **Реальные DXA (A1–A6)** — самое ценное, но без меток качества. Даже без меток годятся для
  самообучения (self-supervised) и для оценки геометрии на другом распределении.
